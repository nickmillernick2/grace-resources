# Grace Resources

AI-powered resource recommendations for church groups & individuals.

## Project Info
- **Owner:** Nick
- **Tech Stack:** React (frontend) + Node.js (backend) + Claude API
- **Timeline:** 6 weeks to MVP
- **Commitment:** 6 hours/week

## Folder Structure
```
grace-resources/
├── backend/          # Node.js API
├── frontend/         # React app
├── docs/             # Project documentation
├── resources/        # Resource library (JSON)
└── README.md
```

## Getting Started
1. Set up backend: `cd backend && npm install`
2. Set up frontend: `cd frontend && npm install`
3. Configure `.env` files
4. Run both servers locally
